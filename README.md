# Suno MP3 Downloader (Windows x64) — v4.0

Десктопное приложение для **Windows 10/11 x64**: скачивает **публичные** треки с
[Suno](https://suno.com) по ссылке и сохраняет их в **MP3 / M4A**.
Интерфейс — минималистичный, тёмная тема, одна строка ввода и крупная кнопка
(в духе sunodownloader.io).

> ⚠️ Приложение предназначено только для публичных треков, доступ к которым
> разрешён самой платформой. Соблюдайте условия использования Suno и авторские
> права на музыку.

---

## Возможности

- 🎵 Вставка ссылки одним кликом (кнопка «Вставить») и очистка (крестик).
- 🔗 Поддержка прямых ссылок `https://suno.com/song/<uuid>` и коротких
  «Поделиться»-ссылок `/s/<code>`.
- 🎚 Выбор формата: **MP3 256 kbps** (по умолчанию), **M4A** (оригинал без
  перекодирования).
- 📁 Выбор папки сохранения (по умолчанию — системная «Загрузки»).
- 📊 Прогресс-бар, статусы на русском, понятные сообщения об ошибках.
- 💾 Карточка результата: название, размер, кнопка «Открыть папку с файлом».
- 🏷 ID3-теги (title/artist) + обложка альбома вшиваются внутрь MP3 (FFmpeg).
- 🧵 Скачивание и конвертация в фоновом потоке — окно не зависает.
- 🧹 Чистые имена файлов (без `\ / : * ? " < > |`), при дублях — `(1)`, `(2)`.
- 📋 **Подробный журнал** `%LOCALAPPDATA%\SunoDownloader\suno_downloader.log`:
  таймстампы до миллисекунды, уровни DEBUG/INFO/WARN/ERROR, полная команда
  FFmpeg, traceback исключений, тайминги этапов. Ротация при 2 МБ. Кнопка
  «📄 Журнал» в GUI открывает файл в проводнике.
- 🖥 **Только x64**: запуск на 32-битном Python блокируется; `build.bat`
  проверяет битность Python и PE-заголовок ffmpeg.exe.
- ⚡ **Без браузера**: скачивание идёт напрямую через API Suno
  (`studio-api-prod.suno.com`) + расшифровка AES-CTR. Chrome/Edge не нужны.

## Запуск из исходников (для разработки)

Требуется **Python 3.10+ 64-bit** (галка «Add Python to PATH»).

```bat
cd SunoDownloader
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

> Для работы конвертации нужен `ffmpeg.exe` (x64) рядом с проектом или в PATH.

## Сборка единого `.exe`

1. **Положите `ffmpeg.exe` (x64!) в корень проекта.**
   Скачайте статическую сборку: <https://www.gyan.dev/ffmpeg/builds/> →
   `ffmpeg-release-essentials.zip` (это 64-битная сборка), распакуйте
   `bin\ffmpeg.exe` и перенесите его в папку проекта как `ffmpeg.exe`.
   ⚠️ Не используйте 32-битные сборки (`ffmpeg-release-essentials.zip` со
   страниц третьих сайтов может быть x86 — проверьте: `ffmpeg -version`).

2. **Запустите сборку:**

   ```bat
   build.bat
   ```

   Скрипт сам проверит 64-битность Python и ffmpeg.exe, создаст `venv`,
   установит зависимости и соберёт бинарник PyInstaller:
   `--onefile --windowed --add-binary "ffmpeg.exe;."`.

3. **Результат:** `dist\SunoDownloader\` — папка с автономным .exe для Windows x64
   (режим onedir, быстрый запуск). Переносите на любой компьютер с Windows 10/11 x64:
   запуск без установки Python и FFmpeg (всё вшито). Консольное окно не появляется
   (`--windowed`). Браузер не требуется.

   > Для одного файла вместо папки: `set MODE=onefile` перед запуском `build.bat`.

## Как это работает (бэкенд)

1. **Разворачивание ссылки** — `requests` с `allow_redirects=True`: короткие
   «Поделиться»-ссылки доводятся до каноничного `https://suno.com/song/<uuid>`;
   UUID извлекается из финального URL или HTML страницы.
2. **Метаданные** — название трека берётся из публичного эндпоинта
   `studio-api-prod.suno.com/api/oembed`.
3. **Права на воспроизведение** — `POST studio-api-prod.suno.com/api/mango/rights`
   (тот же запрос, что делает веб-плеер Suno). Возвращает зашифрованные ключи.
4. **Скачивание** — зашифрованный аудиопоток (.m4a) с CDN CloudFront
   (`d2lwuy8qc234o3.cloudfront.net/1/clip/<uuid>.m4a`).
5. **Расшифровка** — ключ контента раскрывается SHA256+AES-GCM, аудио
   расшифровывается AES-CTR (алгоритм идентичен воспроизведению в браузере),
   библиотека `cryptography`.
6. **Конвертация** — FFmpeg: MP3 256 kbps (`libmp3lame`, ID3v2.3) с вшиванием
   title/artist и обложки; M4A — сохранение оригинала без перекодирования.
7. **Обложка** — последовательно пробуются 3 CDN: `cdn2.suno.ai/image_large_`,
   `cdn.suno.ai/image_large_`, `cdn2.suno.ai/image_`.
8. **Сохранение** — чистое имя + уникализация в выбранную папку.

Весь процесс идёт в отдельном `threading.Thread`; GUI получает статус и
прогресс через очередь и обновляется таймером `after()`. Временные файлы
удаляются в `finally`. Браузер не запускается.

## Журнал (диагностика)

Файл `suno_downloader.log` создаётся в `%LOCALAPPDATA%\SunoDownloader\` при
каждом запуске (кнопка «📄 Журнал» в GUI открывает его в проводнике). Формат:

```

[2026-11-21 14:32:08.456] [INFO ] [RESOLVE] Resolved via GET: <uuid>
[2026-11-21 14:32:08.789] [INFO ] [META]   Title: My Song

[2026-11-21 14:32:14.345] [INFO ] [DOWNLOAD] Downloaded 3245 KB (.m4a)
[2026-11-21 14:32:14.678] [INFO ] [DECRYPT] Decrypted OK: 3245 KB
```

При ошибке — полный traceback (строки `TB|`). Если проблема повторяется —

## Устранение неполадок

| Симптом | Решение |
|---|---|
| «Не удалось определить ID трека по ссылке» | Скопируйте прямую ссылку вида `https://suno.com/song/<uuid>` (из адресной строки после перехода). |
| «Ошибка расшифровки аудио» | Ключи доступа устаревают быстро — просто повторите попытку через минуту. |
| «Не удалось скачать аудиопоток» | Трек приватный/удалён или CDN временно недоступен. Попробуйте другой публичный трек. |
| «Нет соединения с интернетом» | Проверьте сеть / прокси. |
| «FFmpeg не найден» | Положите x64 `ffmpeg.exe` рядом с программой и пересоберите через build.bat. |
| Окно не открывается после сборки | Антивирус мог заблокировать onefile — добавьте исключение; проверьте журнал. |
| Программа пишет, что система 32-бит | Установите 64-битный Python и пересоберите. |
